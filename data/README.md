# Synthetic dashboard data

`oxxo_synthetic_store_data.csv` contains the 300 fictional stores used by the dashboard for the four weeks ending September 27, 2026.

The file is generated by `export-data.cjs`, which uses the same deterministic formulas as the interactive dashboard. It contains no OXXO, FEMSA, recruiter, customer, employee, or other confidential information.

## Field groups

- **Store scope:** period, store, market, district, cohort, and open days
- **Commercial:** inside sales, transactions, fuel gallons, fuel margin, and prior-year comparables
- **Profitability:** inside and fuel gross profit, labor, fees, other controllable costs, contribution, plans, and variance
- **Categories:** sales and gross profit for food, packaged beverages, tobacco, and other merchandise
- **Operations:** labor hours, dispenser hours and telemetry, priority-item audits, inventory, and cost of goods sold
- **Customer behavior:** identified inside and fuel transactions plus linked fuel-to-inside purchases

Dollar fields are in U.S. dollars. Rates stored as decimals should be formatted as percentages when analyzed. Fuel margin fields are dollars per gallon. Counts may contain decimals where the simulated dataset aggregates modeled activity.
